# Намёк

Командная игра в слова-ассоциации для своей компании. На поле 25 слов, у каждой команды свои. Капитан видит, чьё какое слово, и даёт намёк: одно слово и число. Команда ищет, что он имел в виду. Одно слово на поле чёрное: открыл его — проиграл.

## Как играть

1. Один создаёт комнату и диктует код из шести цифр. Остальные входят по коду.
2. Разбейтесь на две команды: в каждой один капитан и хотя бы один отгадчик. Хост может перемешать команды одной кнопкой или перетащить людей.
3. Капитан пишет намёк и выбирает число. Отгадчики нажимают на слово, чтобы отметить его для команды, и «Открыть», когда согласны.
4. Своё слово — можно угадывать дальше (попыток на одну больше числа). Чужое или нейтральное — ход переходит. Чёрное — партия проиграна.

Хост может загрузить в комнату свои слова: только свои или вперемешку с общим словарём. Таймер на намёк и на угадывание включается в лобби.

**Предложить слово** в общий словарь можно с главного экрана и из комнаты. Оно появится у всех после проверки.

## Как устроено

Партию считает сервер `namek.wkiseven.me`: правила, раскладка, таймеры. Ключ цветов уходит только капитанам, поэтому подсмотреть его в окне отгадчика нельзя. Если связь пропала, игра сама вернёт тебя на то же место. Сервер переживает перезапуск: комнаты сохраняются на диск.

## Разработка

```bash
npm install
npm run server      # сервер на :8787 (словарь засевается из server/seed-words.txt)
npm run web         # интерфейс в браузере: ?server=http://127.0.0.1:8787&profile=a
npm run dev         # то же в Electron
npm test            # правила, комната, словарь
npm run typecheck && npm run lint
```

`?profile=a`, `?profile=b` разводят профили по вкладкам, чтобы сыграть за нескольких в одном браузере.

```
src/engine      правила игры (чистые функции)
src/protocol    сообщения клиент ↔ сервер и то, что видит каждый игрок
src/client      сессия клиента
src/renderer    интерфейс (React)
src/main        оболочка Electron, автообновление
server/         комнаты, словарь (SQLite), HTTP/WS; выкат server/deploy.sh на russia
server/modbot/  бот модерации слов в Телеграме; выкат server/modbot/deploy.sh на nether
```
